# Federal Agent Templates

This guide outlines the federal agent templates, including:

1. **HR Benefits Assistant** - Assists with federal HR inquiries.
2. **IT Helpdesk** - Provides IT support for federal systems.
3. **FOIA Assistant** - Aids Freedom of Information Act requests.
4. **Contract Inquiry Assistant** - Answers procurement queries.
5. **Citizen Services Assistant** - Guides public on federal services.
6. **Veteran Benefits Navigator** - Helps navigate VA benefits.
